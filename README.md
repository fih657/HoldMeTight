# HoldMeTight (NeoForge port)

This is a port of the HoldMeTight mod to Minecraft **1.21.1** for **NeoForge**.

## Building

Requirements: Java 21 and a JDK.

```
./gradlew build
```

The compiled jar is output to `build/libs/`.

## Running the client

```
./gradlew runClient
```
